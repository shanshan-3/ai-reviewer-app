# Development

For installation after cloning, follow the [installation guide](installation.md). It covers prerequisites, dependencies, environment files, startup, Android preview, and setup checks.

The installation guide also explains [Expo Go, the RebyuIT Dev APK, and release APKs](installation.md#4-choose-how-to-run-the-android-app). Use the Dev APK for project development; Expo Go provides a limited preview. JavaScript and styling edits reload through Metro, while native changes require rebuilding the APK.

Before removing Android Studio, the SDK, Java, or build caches, read the [Android development cleanup guide](RebyuIT_Android_Dev_Cleanup_Guide.md). An installed, compatible Dev APK can keep loading JavaScript through Metro over the network after local build tools are removed.

Use the [folder guide](../folder-structure.md) to find files and the [roadmap](../planning/ai-powered-reviewer-roadmap.md) for the agreed features and remaining work.
